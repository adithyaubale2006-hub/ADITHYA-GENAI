### PROJECT AI-AUDIO-TRANSLATION

* Build using the google Gemini Api key 
* integration with python Framework Flask, Html/css

### FOLDER STURCTURE
```text
AUDIO-TRANSLATION/
├── SOURCE/
│   └── INDEX.html       # Frontend interface
├── APP.py               # Main application entry point
├── DEMO.PY              # Demo application for testing and practice
└── requirements.txt     # Python dependencies
```


### STEPS
* download the zip file from the repo
* Extract Everthing
* Create a Virtual environment
* activate it -> conda activate audio_bot
* check the path of the folder if you are running in bash ?  C:/"path of folder"
* install the requirements -> pip install -r requirements.txt
* if the current server dosent work change the port to make it work
* run -> python app.py
