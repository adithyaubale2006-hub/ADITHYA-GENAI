# PromptHire

PromptHire is an AI-powered Interview Question and answer Generator.

## Setup Instructions

Step : 1
##### **Create Environment**
> conda create -n hr python=3.12 -y

Step : 2
##### **Activate Environment**
> conda activate hr

Step : 3
##### **Install Requirements**
> pip install -r requirements.txt

## Run the Web Application

> python app.py

## Utilities & Tech Stack

1. Python
2. Jupyter Notebook
3. Nvidia API Key
4. LangChain Framework
5. HTML/CSS
6. LLMs
